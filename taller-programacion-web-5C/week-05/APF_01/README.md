# Café Raíces

Sitio web estático para una cafetería ficticia llamada Café Raíces.

## Página en vivo

https://monorepo-university.vercel.app/

## Páginas

- `index.html` — Acerca de nosotros (historia, misión, visión y valores).
- `menu.html` — Menú de bebidas y platos.
- `reservas.html` — Formulario para reservar una mesa.
- `contacto.html` — Información de contacto.

## Estructura

```
APF_01/
├── css/styles.css
├── js/script.js
├── index.html
├── menu.html
├── reservas.html
└── contacto.html
```

## Tecnologías

HTML5, CSS3 y JavaScript vanilla.

## Uso

Abrir `index.html` en el navegador.
